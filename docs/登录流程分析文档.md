## 一、概述

本文档详细分析 MediaHub 系统与用户中心（User Center）之间的登录跳转流程，包括：
- 前端跳转到用户中心
- 用户中心登录页面
- 微信扫码登录流程
- 登录成功后跳转回原系统
- 各环节的代码位置说明

export function getUrlParameter(name:string) {
    name = name.replace(/[[]/, '\\[').replace(/[\]]/, '\\]');
    var regex = new RegExp('[\\?&]' + name + '=([^&#]*)');
    var results = regex.exec(window.location.search);
    return results === null ? '' : decodeURIComponent(results[1].replace(/\+/g, ' '));
}

#### 轮询检测代码（核心）

let count = 0;
// ★★★ 每秒轮询检测扫码状态 ★★★
const timer = setInterval(() => {
  loginOfficialCallback({sys:sys,ticket:data.loginMethods.wx_qrcode.ticket.value})
    .then((res) => {
      // ★★★ 如果后端返回 redirect_url，说明登录成功 ★★★
      if (res.data && res.data.redirect_url != "") {
        clearInterval(timer)
        // ★★★ 跳转到 redirect_url（原系统页面）★★★
        window.location.href = res.data.redirect_url
      }
      count ++;
      // 二维码有效期 180 秒（3分钟）
      if (count >= 180) {
        clearInterval(timer)
        ElMessage({
          showClose: true,
          message: "二维码已过期，请刷新页面",
          type: 'error',
        })
      }
    })
}, 1000)
```

export function loginOfficialCallback<T=any>(params:officialCallbackParams){

}

#### 跳转流程
```

后端根据 sys 参数查找 internalSystemEntry
    ↓

#### Cookie 工具函数
```typescript:8:17:user-master\user-web\src\utils\utils.ts
export function getCookieValue(key:string) {
    const cookies = document.cookie.split(';');
    for (let i = 0; i < cookies.length; i++) {
      const cookie = cookies[i].trim();
      if (cookie.startsWith(`${key}=`)) {
        return cookie.substring(key.length + 1);
      }
    }
    return null;
}
```

## 六、如何新增系统配置

如果要新增一个系统接入用户中心登录，需要修改以下配置：

### 6.1 用户中心后端配置

修改 `user-master/user/dev.config.yaml`：

```yaml
internalSystemEntry:
  mediahub: "https://localhost:8080"    # 已有
  transform: "http://localhost:8084"  # 已有
  tunnel: "http://localhost:5173"     # 已有
  shorturl: "http://localhost:4000"   # ★ 新增
```

### 6.2 新系统前端配置

在 `.env.development` 中添加：

```bash
VITE_USER_CENTER="http://localhost:8082?sys=shorturl"
```

### 6.3 新系统前端跳转代码

登录跳转代码无需修改，只需修改环境变量即可：

```vue
window.location.href = import.meta.env.VITE_USER_CENTER
// 实际跳转: http://localhost:8082?sys=shorturl
```

## 八、注意事项

1. **Cookie 域名配置**：确保各系统的 Cookie 域名配置一致，才能实现跨系统登录状态共享
2. **sys 参数必须匹配**：前端跳转时的 `sys` 参数必须与后端 `internalSystemEntry` 配置的 key 一致
3. **二维码有效期**：前端轮询最多 180 秒（3分钟），超时需刷新页面重新获取二维码
4. **HTTPS 配置**：生产环境需确保所有地址使用 HTTPS
